# DeepAquaVision

## 🚀 Overview

DeepAquaVision is an AI-powered underwater image enhancement system built to restore clarity, color, and visibility in degraded underwater images. Unlike basic filters, AquaVision uses deep learning to intelligently reconstruct images — making them look clear, natural, and vivid.

It uses an advanced GAN (Generative Adversarial Network) pipeline powered by:

🧠 U-Net Generator with Skip Connections
🤖 PatchGAN Discriminator
🧩 PyTorch Deep Learning Framework
🎨 Streamlit Web Interface

DeepAquaVision is not just an image filter — it feels like a professional photo restoration tool.

---

## ✨ Features

### 🖼️ Smart Image Enhancement
- Removes blue/green color cast
- Restores natural colors
- Improves visibility and contrast

### 🧬 GAN-Based Restoration
- U-Net encoder-decoder with skip connections
- Adversarial training for realistic outputs
- PSNR metric evaluation
- No manual tuning needed

### 🌊 Underwater Mode Includes:
- Haze removal
- Color correction
- Contrast enhancement
- Detail preservation

### ⚙️ Interactive Web App
- Upload and enhance in one click
- Before/after comparison view
- Download enhanced image
- Super-fast inference
